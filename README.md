## Native Language Text Analysis using Natural Language Processing

This project analyzes text written in native languages using basic Natural Language Processing (NLP) techniques. It focuses on preprocessing user input text and extracting meaningful information.

### Project Preview
User inputs text → text is cleaned and tokenized → processed output is generated.

### Features
- Text cleaning
- Tokenization
- Basic text analysis

### Technologies Used
- Python
- Natural Language Processing (NLP)
